# Tasks: Pawn Gear Reroll

**Input**: Design documents from `specs/001-pawn-gear-reroll/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md),
[data-model.md](data-model.md), [contracts/](contracts/), [quickstart.md](quickstart.md)

**Tests**: no automated test project. RimWorld types can't run outside the game (plan.md,
Testing). Each story instead ends with an **in-game verification task** that runs the matching
[quickstart.md](quickstart.md) rows through the `rimworld-mod-testing` skill (Principle VI).

**Organization**: tasks are grouped by user story, so each story can be built and verified on
its own.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: the user story the task belongs to (US1–US6)
- All paths are relative to the repo root `C:\RimWorldDev\Downgrade`

## Conventions for every task

- Namespace `Downgrade`. Source lives under `Source/`, following the `rimworld-modding` skill.
- Every user-facing string goes through `Languages/English/Keyed/Downgrade.xml` with a
  `Downgrade.` key prefix. Era names use the game's own `TechLevel.ToStringHuman()`.
- Every log line uses the exact formats in [contracts/log-contract.md](contracts/log-contract.md)
  through `Source/Core/DLog.cs`. Use `Log.Warning` for failures and `Log.Error` only when one of
  Downgrade's own invariants breaks.
- No compile-time reference to any mod but Harmony. Where an API differs between 1.6 and 1.7,
  branch at the call site with `#if NET10_0_OR_GREATER`.
- Every balance number comes from `Downgrade_Tuning`, `Downgrade_MaterialEras`,
  `Downgrade_StarterTraits` or `DowngradeSettings`, never a bare literal in logic (Principle IV).
- "Build" means `dotnet build` from `Source/`. It must compile **both** `net472` and `net10.0`
  with no warnings introduced by the task, and deploy to RimWorld's `Mods/Downgrade` folder.
- Before using a RimWorld API whose signature isn't quoted in [research.md](research.md), check it
  against the referenced assembly for **both** targets (Krafs 1.6 and 1.7 refs).

## Phase 3: User Story 1 — Downgrade one raider's weapon and apparel to an era (Priority: P1) 🎯 MVP

**Goal**: selecting one eligible pawn shows a Reroll button. Picking an era replaces every
above-era weapon and apparel item with era gear of the same role or slot, bought from the base
value of what was replaced, in era materials. The budget is recorded on the pawn.

**Independent Test**: on 1.7, spawn an Industrial/Spacer-armed hostile with Dev Mode, select it,
